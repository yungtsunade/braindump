# Brain Dump

Kleine Handy-App für den regelmäßigen Brain Dump – im Writy-Look.

1. **Dump** – alles raus, Bulletpoints entstehen automatisch.
2. **Sortieren** – jeder Punkt bekommt eine Markierung: ⭕ Datum, ⭐ Zeitslot (beide mit Google-Kalender-Link) oder ➡ nächster Schritt.
3. **Listen** – Masterliste plus eigene Listen (HEUTE max. 5).
4. **Erledigt** – das Beweisglas.

Alle Daten bleiben lokal im Browser des Geräts. Sicherung unter OPTIONEN.

## Veröffentlichen (GitHub Pages)

Alle Dateien in ein Repo hochladen → Settings → Pages → Branch `main`, Ordner `/ (root)`.
Dann die Seite am Handy öffnen und „Zum Startbildschirm hinzufügen“ bzw. „App installieren“ wählen.

Bei Änderungen in `sw.js` die Versionsnummer in `CACHE` erhöhen.
